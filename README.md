# 📊 Student Performance Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of student performance data using Python. The analysis helps identify patterns, relationships, and factors affecting student scores in math, reading, and writing.

The project includes:

* Data Cleaning
* Handling Missing Values
* Encoding Categorical Data
* Univariate Analysis
* Bivariate Analysis
* Multivariate Analysis
* Data Visualization
* Correlation Analysis

---

# 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

# 📂 Dataset Features

The dataset contains the following columns:

| Feature                     | Description                  |
| --------------------------- | ---------------------------- |
| gender                      | Student gender               |
| race/ethnicity              | Student race/ethnicity group |
| parental level of education | Parent education level       |
| lunch                       | Lunch type                   |
| test preparation course     | Completed or none            |
| math score                  | Math marks                   |
| reading score               | Reading marks                |
| writing score               | Writing marks                |

---

# 🧹 Data Preprocessing

Performed the following preprocessing steps:

* Checked missing values
* Handled NaN values
* Grouped education levels into categories (A–F)
* Encoded categorical columns
* Sorted and cleaned dataset

---

# 📈 Univariate Analysis

Performed analysis on:

* Score distributions
* Group frequency distributions
* Gender distributions
* Education group distributions

### Visualizations Used

* Histogram
* Countplot
* Pie Chart

### Key Insights

* Group F had the highest number of students.
* Group A had the lowest representation.
* Most students scored in the middle range.
* Dataset distribution was uneven across groups.

---

# 📊 Bivariate Analysis

Compared relationships between:

* Math vs Reading
* Math vs Writing
* Reading vs Writing
* Completed vs None students
* Education groups vs scores

### Visualizations Used

* Scatterplot
* Bar Graph
* Boxplot

### Key Insights

* Students who completed the test preparation course performed better.
* Reading and writing scores showed strong positive correlation.
* Higher parental education levels were associated with better scores.
* Students with no preparation generally scored lower.

---

# 📉 Multivariate Analysis

Analyzed relationships among:

* Math Score
* Reading Score
* Writing Score
* Gender
* Education Groups
* Test Preparation Course

### Visualizations Used

* Pairplot
* Heatmap
* Multivariate Scatterplot

### Key Insights

* Strong correlation existed between reading and writing scores.
* High-performing students generally scored well in all subjects.
* Test preparation positively affected overall academic performance.
* Academic performance patterns were consistent across subjects.

---

# 🔥 Group-wise Analysis

Education groups were created as:

| Group | Education Level    |
| ----- | ------------------ |
| A     | Master's Degree    |
| B     | Bachelor's Degree  |
| C     | Associate's Degree |
| D     | High School        |
| E     | Some High School   |
| F     | Some College       |

### Group-wise Findings

* Group F contained the highest student frequency.
* Groups C, D, and F dominated the dataset.
* Completed students consistently outperformed none students.
* Group-wise performance differences were clearly visible.

---

# 📌 Overall Findings

* Test preparation significantly improved student scores.
* Reading and writing scores were highly correlated.
* Students with educated parents tended to perform better.
* Group distributions were not balanced.
* Most students belonged to middle and higher education groups.

---

# ✅ Final Conclusion

This project successfully analyzed student academic performance using Exploratory Data Analysis techniques.

The analysis revealed that:

* Test preparation courses positively impact student performance.
* Reading and writing abilities are strongly connected.
* Parent education level influences academic achievement.
* Students who completed preparation courses consistently achieved higher scores.
* Data visualization helped identify hidden trends and relationships in the dataset.
